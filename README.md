# 自定义娱乐

AstrBot 娱乐插件。**59 个菜单 / 8 大分类**，所有功能支持**按群独立开关**，数据全部本地 JSON 持久化。

> 版本 1.4.0 · AstrBot ≥ 4.27
> 上架版：不含音乐点歌、图鉴、B站、油价、猜拳

---

## 功能一览

发 `主菜单` 打开，8 个入口：

| 入口 | 内容 |
|---|---|
| 🎭 **接口系统** | 表情包 API 规则（关键词 → 图片/视频）、接口功能、接口管理 |
| ⛏️ **MC系统** | Minecraft Java 版版本检测与自动推送 |
| 📅 **打卡系统** | 早安/晚安打卡、打卡排行、打卡统计 |
| 💰 **签到系统** | 签到、积分、银行（存/取/理财/借贷/抢银行）、商店、坐骑、打工、抽奖、神偷、查询 |
| 🎲 **每日系列** | 今日运势、今日老公、今日人品 |
| 🎈 **娱乐功能** | 赛车、猜数、天气查询 |
| 💬 **发言功能** | 发言统计与排行 |
| 🔧 **管理系统** | 各类管理指令说明与开关 |
| 🔑 **授权功能** | 按群授权（管理系统下级） |

## 详细功能

### 接口系统
- 关键词触发 API，支持 **5 个占位符**（`{qq}` / `{text}` / `{pic}`）
- 关键词前/后、@ 前/后均可；**空格可有可无**（`外星人说你好` 也认）
- 参数不足静默不回复；URL 模板后台可改，自动迁移旧格式
- 支持无参数接口，可返回图片或视频

### 打卡系统
- 全群统一打卡（不分群），记录每天起床/睡觉时间
- 起床显示睡眠时长，睡觉显示清醒时长；必须当天打过早安才能打晚安
- 逻辑日每天 6 点重置；早安/晚安各有时间窗口与重复次数限制
- **打卡查询拆成三条独立指令**：打卡天数排行 / 清醒时长排行 / 睡眠时长排行（各取前十）
- 文案可在后台增删改（含起止小时），内置 7+7 条

### 签到系统
- **签到**：每天一次，随机 1-1000 积分，展示连续天数/名次/今日发言等
- **排行榜**：积分榜 + 连续榜 + 银行富豪榜
- **银行**：存/取（支持 `all`）、日利率结算（默认 1%）、理财、借贷、抢银行
- **商店 / 坐骑**：消耗积分购买，坐骑可装备，**装备后每天群里第一句话会提示登场**
- **打工**：多工种、独立冷却、收益随机；可「加班」追加次数
- **抽奖 / 神偷**：抽奖消耗积分；偷积分成功/失败/反拿概率均可配
- **数据按群独立**：`users[群号][用户号]`，旧数据自动迁移

### 娱乐功能
- **赛车**：买车 → 装备 → 比赛。五项属性（速度/加速/操控/稳定/幸运）决定胜率，
  用**用时模拟**而非纯随机，结果可解释
  - 报名满 5 人开赛，1 小时没满自动补 NPC；「快速比赛」全是 NPC
  - 报名费进奖池 + 当天系统随机加成，前三名按 50%/30%/20% 瓜分
  - 抽奖限定车**不会重复抽中**，抽光后转积分奖；NPC 强度可调（建议 100%~130%）
  - 四个数据列表（商店在售 / 抽奖限定 / 抽奖奖池 / NPC 用车）后台可增删改
- **猜数**：开新局 → 群友猜 → 结算，范围与奖励可配
- **天气查询**：多接口回退

### 每日系列
运势 / 老公 / 人品，每人每天一次，当天固定，次日刷新。

> **彩蛋**：运势与人品是两套独立算法，所以会出现「玄学组合」——
> 大凶 + 大吉 = 玄学对冲全看命硬不硬；大凶 + 大凶 = 建议直接躺平 🎲

### 其他
- **整点报时**：按群开关、可指定时段、自定义文案（`{hour}`）
- **定时状态推送**：每日固定时间推送主机状态
- **每日读报**：手动读报与自动推送是**两个独立名单**，开关互不影响
- **词库**：关键词回复，支持换行、黑白名单、单群屏蔽
- **发言统计**：每日/累计/连续活跃，排行榜
- **授权功能**：按群授权，未授权群插件完全静默

### 退群清数据
AstrBot 无「成员减少」事件，改成两个动作：
- **查询时过滤**：拉本群成员名单，不在名单里的不上排行榜
- **顺手真清**：把已退群成员的本群数据删掉

三重安全阀，**绝不误删**：名单拉不到 → 不过滤；名单人数不足记录 1/3 → 判定残缺、什么都不删；5 分钟缓存。

## 权限

| 等级 | 判定方式 |
|---|---|
| **AstrBot 全局管理员** | AstrBot 平台配置的 `admins_id`，拥有全部权限 |
| **插件专属管理员** | 后台「超管设置」配置，跨群拥有插件管理权限 |
| **群主 / 群管理员** | 群身份自动识别，群内管理指令权限 |
| 普通成员 | 其余 |

- 授权 / 冻结 / 加减积分 → **只认全局管理员**
- 坐骑 / 宠物 / 工种 / 群管开关 → 全局 + 专属 + 群主 + 群管
- 查询类（授权状态、授权列表）→ 所有人

## 表情包占位符

| 占位符 | 类型 | 行为 |
|---|---|---|
| `{qq}` / `{qq1}` / `{qq2}` | QQ 号 | 纯数字或 @某人都行；不是数字/QQ 时静默 |
| `{text}` / `{text1}` / … | 文本 | 任意文本直接使用 |
| `{pic}` / `{pic1}` / … | 任意 | 兼容旧配置，不校验 |

```
上香 1142479412          上香@某人
鞭打 1142479412 123456   鞭打@某人@某人
报悲 我是煞笔
```

## 数据存储

| 文件 | 内容 |
|---|---|
| `*_data.json` | 11 组数据集合（接口规则/运势/词库/坐骑/工种/文案/宠物/事件/物品…）+ `menu_texts` 菜单文案 |
| `*_checkin.json` | 签到、积分、银行、理财、借贷、打工冷却 |
| `*_pet.json` | 宠物（等级/经验/属性/五行/背包） |
| `*_greeting.json` | 打卡记录与逻辑日列表 |
| `*_nickname.json` | 跨群昵称缓存 |
| `*_speak_stats.json` | 发言统计 |
| `*_hourly_chime.json` / `*_minecraft.json` / `*_status_push.json` | 各功能的开关、时间与推送通道 |

- 全部**原子写入**（临时文件 + 重命名），断电不损坏
- 旧版本数据自动迁移
- 菜单文案改动后**重载插件**生效（内存副本优先）

## 后台面板

独立 HTML 页面，左侧导航。

- 所有配置项可视化编辑，**说明统一收到页面最下方、合并进一个框**（带收起/展开）
- **📊 数据统计**（左侧第一个按钮，**只读**）：收到/发送消息累计、调用次数、
  指令执行数、用户数量、错误次数、目前加入群数量、加入/退出群次数、在线时长、
  未到期/到期群数，每项一个方格；另有版本 / 菜单数 / 配置项 / Web 路由等明细
  - 全部数字**本地计算，不采集隐私、不上报**
  - 路由只有 `GET`，页面无保存入口
- **数据管理**：11 组集合的增删改查
- **授权状态列表**：每个群的授权状态与到期时间
- 菜单文案、页面素材、背景图均可改

## 注意事项

- **车型/坐骑图已移除**，统一纯文本输出（不连任何渲染服务）
- **点歌等音乐功能不在上架版**（市场版无音乐模块）
- **二维码识别**：优先本地库，失败再走配置的接口
- **转发聊天记录里的图片识别不到**：`Forward` 段只带一个 id，需要额外取内容（未支持）
- **退群清数据**靠「查询时过滤 + 顺手真清」，有 3 重安全阀不会误删
